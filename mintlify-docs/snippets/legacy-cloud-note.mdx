  **Looking for the `@mentra/sdk` cloud SDK?** Apps used to be cloud-hosted

  Miniapp SDK (`@mentra/miniapp`), which these docs cover. The older cloud SDK
  docs live at [mentraglass.com/legacy](https://mentraglass.com/legacy).
</Info>
