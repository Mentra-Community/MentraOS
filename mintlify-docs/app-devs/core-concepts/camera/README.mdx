---
title: "Camera, Photos, And Streaming"
description: "Use the Bluetooth SDK for camera, photo, and streaming features."
---

The Mentra Cloud SDK (`@mentra/sdk`) is for cloud Mini Apps that run through MentraOS sessions. For camera capture, photo upload, video streaming, RTMP/SRT/WHIP ingest, or direct phone-to-glasses camera flows, use the Mentra Live Bluetooth SDK docs instead:

<CardGroup cols={2}>
  <Card title="Bluetooth SDK Docs" icon="bluetooth" href="/mentra-live/overview">
    Build mobile apps that connect directly to smart glasses and control camera/photo/streaming features.
  </Card>
  <Card title="Camera And Streaming" icon="camera" href="/mentra-live/camera-streaming">
    Request photos and start RTMP, SRT, or WebRTC streams from supported smart glasses.
  </Card>
</CardGroup>

If you are building a cloud Mini App, continue with the App Devs docs for server-side sessions, transcription, display output, permissions, storage, phone events, location, and dashboard UI.
