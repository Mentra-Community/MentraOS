`session.display` draws to the glasses HUD. Every method is fire-and-forget: it
returns `void`, sends one message to the phone, and doesn't wait for an ack. Call
it again to replace what's on screen.

```typescript
session.display.showTextWall("Hello from MentraOS");
```

Display needs no permission, but the glasses do need a screen. Declare a `DISPLAY`
hardware requirement in your [manifest](/app-devs/core-concepts/miniapp-manifest)
so the miniapp only installs on glasses that can show anything.

## Layouts

```typescript
// One block of text, filling the view.
session.display.showTextWall("Recording…");

// Two stacked rows.
session.display.showDoubleTextWall("Speaker 1", "Speaker 2");

// A titled card.
session.display.showReferenceCard("Next stop", "Powell St., 2 min");

// A base64 PNG/JPEG. The phone converts it to the glasses' native format.
session.display.showBitmapView(base64Png);

// Clear the screen.
session.display.clear();
```

| Method | Shows |
|---|---|
| `showTextWall(text, options?)` | A single block of text. |
| `showDoubleTextWall(top, bottom, options?)` | Two stacked rows. |
| `showReferenceCard(title, text, options?)` | A title and a body. |
| `showBitmapView(data, options?)` | A base64-encoded PNG/JPEG. |
| `showDashboardCard(left, right)` | A two-column card in the dashboard view. |
| `clear(view?)` | Clears `"main"` (default) or `"dashboard"`. |

## Options

Most methods take a `DisplayOptions` object:

```typescript
session.display.showTextWall("Saved", { durationMs: 2000 });
```

| Field | Type | What it does |
|---|---|---|
| `view` | `"main" \| "dashboard"` | Which surface to draw on. Defaults to `"main"`. |
| `durationMs` | `number` | Auto-clear after this many milliseconds. |
| `breakMode` | `"character" \| "character-no-hyphen" \| "word" \| "strict-word"` | How text wraps. Applies to the text-wall and reference-card layouts. |

## Positioned content (G2)

On Even Realities G2, the display is a 576×288 canvas you can place content on by
coordinate. `showBitmapView` and `showTextAt` take `x`, `y`, `width`, and
`height` for the target container; omit them for default placement.

```typescript
// A 100×100 image pinned to the bottom-right corner.
session.display.showBitmapView(base64Png, { x: 476, y: 188, width: 100, height: 100 });

// A bordered label at the bottom-left.
session.display.showTextAt("TEST", {
  x: 0, y: 201, width: 120, height: 87, borderWidth: 2, borderRadius: 6,
});
```

`showTextAt` is G2-only. On glasses without positioned containers, use the
full-view layouts above. For drawing several positioned containers onto one page,
see [`session.canvas`](/app-devs/core-concepts/canvas), the lower-level API the
display layouts build on.

## Dashboard view

`showDashboardCard` (and any method with `view: "dashboard"`) targets the
dashboard view, the glasses' status view that the user brings up with a
glasses-specific gesture (head-up on G1, a double-tap on others).
