`session.canvas` is the lower-level drawing API that
[`session.display`](/app-devs/core-concepts/display/layouts) builds on. Most
miniapps should use `session.display`: it's simpler and covers the common
layouts. Reach for `canvas` when you need to place several text and bitmap
containers onto one page yourself.

Every method is fire-and-forget and returns `void`. Coordinates are on the
glasses' 576×288 canvas.

```typescript
session.canvas.showText("Battery 80%", { x: 0, y: 0, width: 200, height: 60 });
session.canvas.showBitmap(base64Png, { x: 400, y: 180, width: 100, height: 100 });
session.canvas.clear();
```

## Methods

| Method | What it does |
|---|---|
| `showText(text, options?)` | Draws text in a positioned container. |
| `showBitmap(data, options?)` | Draws a base64 PNG/JPEG. The phone converts it to the glasses' native format. |
| `showPage(id, options?)` | Switches to a named page. |
| `clear(options?)` | Clears the canvas (or a specific `page_id`). |

## Options

The options share a container box, plus a few text-only fields:

| Field | Type | Applies to | Notes |
|---|---|---|---|
| `x`, `y` | `number` | text, bitmap | Top-left of the container on the 576×288 canvas. Omit for default placement. |
| `width`, `height` | `number` | text, bitmap | Container size. |
| `borderWidth` | `number` | text | Border stroke in px. `0` for none. |
| `borderRadius` | `number` | text | Corner radius in px. |
| `page_id` | `string` | all | Targets a specific page. |

<Note>
Positioned drawing is a G2 capability. On glasses without positioned containers,
use the full-view layouts in [`session.display`](/app-devs/core-concepts/display/layouts).
</Note>
