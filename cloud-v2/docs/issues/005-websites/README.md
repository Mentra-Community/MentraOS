# 005 Websites

Umbrella issue for the Mentra web frontends. Each site pairs with a Cloud Core
service (see [`../001-cloud-core/`](../001-cloud-core/)).

## Sites (subfolders)

- [`console/`](./console/): Developer Console. Backed by
  [`../001-cloud-core/dev-console-service/`](../001-cloud-core/dev-console-service/).
- [`miniapp-store/`](./miniapp-store/): the App / MiniApp Store. Backed by
  [`../001-cloud-core/miniapp-service/`](../001-cloud-core/miniapp-service/).
- [`oem-portal/`](./oem-portal/): OEM Portal. Backed by
  [`../001-cloud-core/oem-service/`](../001-cloud-core/oem-service/) and oem-auth.
  Existing spike.
